# Weather Forecasting Web Application

A lightweight, full-stack web application built to provide real-time weather updates and forecasts.

## 🛠️ Tech Stack

*   **Backend:** Python, Flask (`app.py`)
*   **Frontend:** HTML5 (`templates/index.html`), CSS3 (`static/css/style.css`), JavaScript (`static/js/script.js`)
*   **Configuration:** Environment variables (`.env`)[cite: 1]
*   **Dependencies Management:** `requirements.txt`[cite: 1]
